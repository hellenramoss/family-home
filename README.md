# Family Home

PWA familiar offline-first para listas compartilhadas, tarefas e compras.

## V1

- Criar listas
- Adicionar, concluir e reabrir itens
- Ocultar itens concluídos
- Contador de pendências
- Concluir/reabrir todos
- Excluir concluídos
- Persistência local no aparelho
- Instalável como PWA

## Rodar localmente

```bash
npm install
npm run dev
```
